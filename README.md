# NSE Stock Price Prediction & Portfolio Optimization

## 📈 Project Overview
This repository contains a comprehensive Time Series Analysis pipeline developed for the **IIT Guwahati C&A Capstone Project 2026**. The project focuses on predicting price movements for a diversified 5-stock portfolio using both traditional statistical methods and modern deep learning.

## 🛠️ Key Features
* **Multi-Model Approach**: Implemented **ARIMA** for statistical trend analysis and **LSTM (Long Short-Term Memory)** networks for capturing non-linear market momentum.
* **Diversified Portfolio**: Analysis of 5 stocks across Power (RPOWER), Banking (ICICI), IT (TCS), Healthcare (Cipla), and FMCG (ITC) sectors.
* **Interactive Dashboard**: A high-fidelity "Cyber-Quant" dashboard featuring a **3D Risk-Volatility Landscape** and real-time forecast validation.

## 🧪 Results
The **LSTM model** achieved remarkable accuracy during the May 15th session, outperforming ARIMA with a **Mean Absolute Percentage Error (MAPE) of <1%**.

## 🚀 Technologies Used
* **Python** (Pandas, NumPy)
* **Finance**: `yfinance`
* **Machine Learning**: `TensorFlow`, `Keras`, `statsmodels`
* **Visualization**: `Plotly`, `Seaborn`
